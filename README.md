# TermX

> 一款为运维与后端开发者打造的现代化 SSH 客户端 —— 把终端、SFTP 文件管理、实时性能监控、命令片段管理与多窗格工作流整合到同一个桌面应用里。

[![Windows](https://img.shields.io/badge/platform-Windows%2010%2B-0078D4?logo=windows)](#下载安装)
[![Version](https://img.shields.io/badge/version-1.0.24-24292e)](#下载安装)
[![License](https://img.shields.io/badge/license-UNLICENSED%20(闭源)-red)](#授权)
[![Channel](https://img.shields.io/badge/channel-stable-4f7cff)](#下载安装)

TermX 是受 FinalShell / Tabby / MobaXtern 启发的桌面 SSH 工具，目标是：**一个窗口做完所有服务器日常操作**。在内置终端之上，叠加了实时性能监控、SFTP 文件浏览器、命令片段库、多标签多分屏、命令面板等能力，免去在终端、SFTP 工具、监控面板之间反复切换的麻烦。

> 本仓库为 **官方发布仓库（闭源）**。源代码不公开，仓库仅用于：发布 Windows 安装包、跟踪问题与功能反馈、发布升级公告。请到 [Releases](#下载安装) 下载最新版本。

## 核心特性

| 能力 | 描述 |
|------|------|
| **多标签 + 多分屏终端** | 一个连接下开多个 shell；同一标签内可水平/垂直任意分屏，构建 2×2、四象限工作区 |
| **实时服务器监控** | 接入后自动采集系统信息、CPU（总览 + 每核心）、内存、负载、磁盘、网络、进程；1 分 / 5 分 / 30 分趋势曲线 |
| **SFTP 文件浏览器** | 双栏文件树 + 列表视图；支持上传、下载、新建、删除、重命名、权限修改、传输队列管理 |
| **命令片段管理** | 把常用命令按分类（运维 / 安装 / 网站 / 其他）归类保存；底部状态栏一键插入到当前终端 |
| **命令面板（Ctrl+P）** | 类 VSCode 的快速命令面板，新建会话、分屏、重连、切换主题、打开设置等全部键盘可达 |
| **多会话 + 多服务器** | 左侧边栏统一管理所有服务器，支持分组、搜索、最近连接 |
| **配色主题与外观** | 内置多套配色方案，深 / 浅主题切换；终端字体、行高、光标样式可调 |
| **企业授权激活** | 客户端通过设备指纹 + 签名校验完成激活，授权状态与服务端同步，支持试用与正式授权 |
| **内置自动更新** | 启动时检查新版本，提示升级；可通过 stable / beta 双通道分发 |

## 界面预览

### 1. 工作台主界面

主界面一屏同时呈现：左侧文件树 / 会话列表、中间多标签终端、右侧实时监控面板、底部命令片段快捷栏。

![主界面](doc/screenshots/01-home.png)

> 图中右侧实时监控显示：系统信息（Ubuntu 24.04.4 LTS / 主机名 / IP / 架构 / 启动时间 / 运行时长）、CPU 总览 + 每核心使用率、内存使用；底部状态栏内嵌 `docker ps` / `服务状态` / `实时日志` / `free -h` / `top` / `disk` / `ports` / `conn` 等运维常用片段。

### 2. 多窗格分屏

同一个服务器连接下，开多个 shell 并做水平/垂直分屏，便于并行观察多个任务。

![多窗格](doc/screenshots/02-multi-pane.png)

> 图中展示了 `shell 1` 与 `shell 2` 左右分屏，左侧 SFTP 文件树常驻，右侧监控面板持续刷新。

### 3. 命令面板（Ctrl+P）

键盘驱动的快速操作入口：新建会话、新建终端、水平/垂直分割、重新连接、切换主题、打开设置等。

![命令面板](doc/screenshots/03-command-palette.png)

### 4. SFTP 文件浏览器

独立的 SFTP 浏览窗口：上方工具栏（上传 / 下载 / 新建 / 删除 / 刷新 / 定位），下方左树右列表双栏布局，列表显示名称、大小、权限、修改时间，底部状态栏显示容量与已选项目。

![SFTP 文件浏览器](doc/screenshots/04-sftp.png)

### 5. 命令片段管理

按分类组织命令片段库，支持搜索、新建、标签过滤；底部状态栏的快捷片段可一键插入到当前终端。

### 安装步骤

1. 双击 `TermX-Setup-1.0.24-x64.exe`。
2. 欢迎页 → 许可协议 → 选择安装目录 → 选择数据目录 → 安装 → 完成。
3. 安装完成后会自动启动 TermX；之后也可从开始菜单或桌面快捷方式启动。

> 安装器使用 Inno Setup 制作，**不需要管理员权限**，默认装到 `%LOCALAPPDATA%\Programs\TermX`，数据目录默认 `%APPDATA%\TermX`。

- **stable**（默认）：正式版，禁用开发者工具（F12）
- **beta**：测试版，启用开发者工具（F12），可提前体验新功能

如需切换通道，请到 [Releases](../../releases) 中手动下载对应版本覆盖安装。

## 快速上手

1. **首次启动** → 完成授权激活（输入授权码，或申请试用）。
2. **新增服务器** → 左侧边栏「+ 新建会话」或使用命令面板 `Ctrl+P` → 「新建会话」，填写主机、端口、用户名、认证方式（密码 / 私钥）。
3. **连接** → 双击会话卡片即可连接；右侧监控面板会自动开始采集。
4. **打开 SFTP** → 在会话内点击左侧路径栏的「打开 SFTP 浏览器」按钮，或使用命令面板。
5. **分屏** → 命令面板 `Ctrl+P` → 「水平分割」/「垂直分割」。
6. **保存命令片段** → 底部状态栏「+ 管理」打开片段管理面板，新建并归类。
7. **快捷键** → 命令面板右上角可查看全部快捷键。

## 主要功能详解

### 终端

- 基于 `xterm.js` + `ssh2`，完整 256 色 / Unicode / 中文支持（`iconv-lite` 处理 GBK 等编码）
- 多标签、多分屏（任意水平/垂直组合），分屏可拖拽合并、互换位置
- 命令历史、命令建议、当前工作目录（CWD）追踪
- 选中即复制 / 右键粘贴，Web 链接可点击
- 支持自定义配色、字体、行高、光标

### 实时监控

- **系统信息**：操作系统、内核、主机名、IP、架构、启动时间、运行时长
- **CPU**：总览百分比 + 每核心使用率（最多支持数十核心），1/5/30 分钟趋势曲线
- **内存**：已用 / 总量 / 百分比，含 Swap
- **磁盘**：分区挂载点、容量、IO 速率
- **网络**：每网卡上下行速率、TCP 连接数
- **进程**：Top N 进程（CPU / 内存），可排序

> 监控数据由 SSH 通道在同一条连接上采集，无需在服务器侧安装 Agent。

### SFTP 文件浏览器

- 双栏布局：左侧远程文件树、右侧当前目录文件列表
- 工具栏：上传、下载、新建目录/文件、删除、重命名、刷新、定位到路径
- 文件属性：名称、大小、权限、修改时间
- 传输队列：底部状态栏显示传输进度，支持断点续传
- 拖拽上传：从本地资源管理器直接拖到 SFTP 窗口

### 命令片段

- 按分类（运维 / 安装 / 网站 / 其他，可自定义）组织常用命令
- 支持标题、描述、命令正文、标签
- 搜索：标题 + 命令正文 + 标签全文检索
- 一键插入：底部状态栏快捷栏点击即可发送到当前终端光标位置

### 命令面板（Ctrl+P）

- 类 VSCode 体验：模糊搜索 + 键盘导航
- 涵盖：会话管理、终端管理、分屏、外观、设置、主题切换、重连、SFTP 等
- 支持自定义快捷键

### 外观与主题

- 内置深 / 浅主题与多套终端配色方案（Dracula / One Dark / Solarized / GitHub 等）
- 字体、字号、行高、光标样式、滚动回看行数可调
- UI 缩放、紧凑模式

| 层 | 技术 |
|----|------|
| 桌面框架 | Electron 32 |

## 系统要求

- **操作系统**：Windows 10 1809+ / Windows 11（64 位）
- **运行时**：无需预装，安装包自带 VC++ Runtime（VCRUNTIME140.dll）
- **磁盘空间**：约 500 MB（安装包 80 MB + 解压后约 300 MB + 缓存）
- **网络**：能访问目标 SSH 服务器（默认 22 端口）即可；激活与更新需要访问 `termx.cn`

> macOS / Linux 版本规划中，目前仅提供 Windows 构建。

## 数据目录与配置

TermX 把程序文件与用户数据完全分离：

| 内容 | 位置 |
|------|------|
| 程序文件 | `%LOCALAPPDATA%\Programs\TermX\` |
| 用户数据（会话、片段、设置、日志） | `%APPDATA%\TermX\`（安装时可选其他目录） |
| 配置标记 | `HKCU\Software\TermX\DataDir` |

数据目录在首次安装时由用户选择；之后所有会话、命令片段、监控配置、日志都写入该目录，**升级不会丢失数据**。

卸载时仅删除程序文件，用户数据目录保留，需要手动清理。

## 隐私与安全

- **不收集敏感数据**：你的服务器凭据（密码 / 私钥）仅保存在本地数据目录，**不会上传**到任何服务器。
- **设备指纹**：客户端使用 Rust Native 模块生成不可逆设备指纹（硬件特征 hash），仅用于授权绑定，不包含可识别个人信息。
- **通信加密**：所有 SSH 会话、SFTP 传输使用 SSH 协议内置加密；授权激活走 HTTPS。
- **服务端通信**：客户端仅与 `https://termx.cn/api` 通信（授权校验、版本更新检查）；可在内网部署模式下切换到私有服务器。
- **无第三方追踪**：不集成任何统计 SDK（无 Google Analytics / Sentry / 友盟等）。

## 升级与更新

- 启动时自动检查新版本（连接 `termx.cn/api` 比对版本号）。
- 发现新版本后会弹窗提示，可选「立即下载」或「稍后」。

- 想跳过自动检查？到「设置 → 通用」关闭「自动检查更新」。

## 常见问题

**Q1：连接服务器后右侧监控面板不显示数据？**
监控采集需要几秒初始化；若超过 10 秒仍为空，请检查服务器是否允许 `top`、`free`、`df`、`/proc` 访问，以及 SSH 会话是否被 `chroot` 或 `rbash` 限制。

**Q2：SFTP 上传大文件中断了怎么办？**
打开底部「传输队列」查看错误；建议在网络稳定时重传。后续版本会支持断点续传。

**Q3：装好之后启动报 "Cannot find module 'ssh-license-native'"？**
通常是杀毒软件拦截了 native 模块。把 `%LOCALAPPDATA%\Programs\TermX\` 加入杀毒白名单后重新安装。

**Q4：试用授权到期了怎么续期？**
在 TermX 内点击「授权管理 → 申请正式授权」或联系销售。

**Q5：内网环境无法访问 termx.cn 怎么办？**
TermX 提供内网部署模式，可把 baseURL 切换到企业私有服务器，请联系商务获取内网版安装包。

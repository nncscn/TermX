# TermX 界面功能介绍

> 本文档基于 TermX 实际运行截图，逐张拆解界面布局、功能模块与操作要点。配套截图位于 `doc/screenshots/`。

---

## 一、主界面（工作台）

![主界面](screenshots/01-home.png)

主界面是 TermX 的核心工作区，**一个窗口同时呈现四大模块**：顶部标题栏、左侧文件树 / 会话栏、中间多标签终端、右侧实时监控面板、底部命令片段快捷栏。

### 1.1 顶部标题栏

- 左侧：应用名称 **TermX** + 版本号
- 右侧功能：
  - **搜索框**（快捷键 `Ctrl + K`）—— 全局快速搜索
  - **主题切换**（太阳 / 月亮图标）
  - **授权剩余天数**（如「30 天」表示授权或试用期剩余）
  - 窗口控制按钮（最小化、最大化、关闭）

### 1.2 左侧边栏（会话 / 文件树）

- **顶部**：当前连接的服务器地址（如 `nncs@192.168.61.127`）+ 刷新 / 设置图标
- **路径导航**：当前工作目录（如 `/home/nncs`）+ 「**打开 SFTP 浏览器**」按钮（文件夹图标）
- **文件目录树**：以树形结构展示服务器根目录 → 用户目录 → 各级子目录
  - 支持展开 / 折叠
  - 隐藏文件以 `.` 开头（如 `.bashrc`、`.config`、`.ssh`）
  - 当前选中目录高亮（浅蓝色背景）
  - 单击目录可切换终端的 CWD

### 1.3 中间终端区

- **标签页**：
  - `SSH` —— 会话信息标签
  - `shell 1` —— 实际终端标签（绿色圆点表示活跃）
  - 「+」—— 新建终端
- **终端内容**：完整支持 256 色 + Unicode + 中文
  - 示例：欢迎信息 `Welcome to Ubuntu 24.04.4 LTS (GNU/Linux 6.8.0-134-generic x86_64)`
  - 命令提示符 `nncs@nncscn:~$`

### 1.4 右侧实时监控面板

- **顶部标题栏**：`实时监控` + 时间范围切换（`1分 / 5分 / 30分`）+ 当前时间
- **服务器信息卡片**：
  - 服务器地址：`nncs@192.168.61.127`
  - 系统：`Ubuntu 24.04.4 LTS · 6.8.0-...`
  - 主机名：`nncscn`
  - IP：`192.168.61.127`
  - 架构：`GNU/Linux`
  - 启动：`2026-07-09 21:26`
  - 运行时长：`2 天 21 小时`（绿色）
- **三个监控标签页**：`性能`（默认）、`进程`、`磁盘`
- **性能监控**：
  - **CPU 使用率（总览）**：状态标签（`正常`）+ 当前值（`0.6%`）+ 平均值（`16 核心 · 均 0.5%`）
  - **每核心使用率**：折线图 + 明细（`max C5 3% · min C1 0%`）+ 各核心负载
  - **可展开收起**：`展开剩余 10 个核心（共 16）`
- **内存使用**：`5.6 / 30.7 GB`（`18.4%`）+ 绿色进度条

### 1.5 底部状态栏（命令片段快捷栏）

从左到右依次为：

| 按钮 | 功能 |
|------|------|
| **快捷** | 打开命令片段管理面板 |
| **+ 管理** | 新建命令片段 |
| `docker ps` | 一键插入：查看运行中的容器 |
| `服务状态` | 一键插入：查看 systemd 服务状态 |
| `实时日志` | 一键插入：查看容器实时日志 |
| `free -h` | 一键插入：查看内存占用 |
| `top` | 一键插入：实时进程视图 |
| `disk` | 一键插入：磁盘占用 |
| `ports` | 一键插入：监听端口列表 |
| `conn` | 一键插入：当前连接 |

- 左侧：**传输队列** - 点击展开（显示 SFTP 文件传输进度）
- 右侧：**已选 0 项**（文件列表选中计数）

### 1.6 配色风格

- 深色主题：深灰 / 黑色背景 + 白色 / 浅灰文字
- 状态色：绿色 = 正常 / 活跃；蓝色 = 选中 / 高亮；红色 = 警告

## 二、多窗格分屏

![多窗格](screenshots/02-multi-pane.png)

多窗格模式让你**在同一窗口里并行处理多个任务**，无需在多个窗口之间切换。

### 2.1 整体布局

- **左侧**：SFTP 文件浏览器（约 1/4 宽度），常驻显示服务器目录结构
- **中间**：终端面板区，多个标签 + 同标签内分屏
- **右侧**：实时监控面板（约 1/4 宽度），随会话切换刷新

### 2.2 终端分屏

- **标签页**：顶部可见 `shell 1` / `shell 2` / `shell 3` / `+`
- **分屏**：当前 `shell 1` 与 `shell 2` 处于左右分屏（各占 50%）
- **每个终端独立**：拥有自己的命令提示符、历史、CWD
- **示例内容**：
  - `shell 1`：Ubuntu 欢迎信息 + 系统文档链接 + `Last login`
  - `shell 2`：仅显示 `Last login` 和命令提示符，等待输入

### 2.3 操作方式

- **新建分屏**：命令面板（`Ctrl+P`）→ 「水平分割」/「垂直分割」
- **关闭分屏**：分屏右上角关闭按钮，或快捷键
- **切换焦点**：鼠标点击目标分屏，或快捷键循环
- **调整大小**：拖拽分屏之间的分隔条

### 2.4 典型场景

| 场景 | 分屏组合 |
|------|---------|
| 编辑 + 运行 | 上：编辑器（vim）；下：运行命令 |
| 日志 + 调试 | 左：实时日志 `tail -f`；右：手动调试命令 |
| 多服务器对比 | 左：生产服；右：测试服（不同会话） |
| 文件操作 + 终端 | 左：SFTP 浏览器；右：终端（已是默认布局） |

## 三、命令面板（Ctrl+P）

![命令面板](screenshots/03-command-palette.png)

命令面板是 **键盘党的核心入口**，按下 `Ctrl+P` 召唤，模糊搜索所有可用操作。

### 3.1 顶部搜索框

- 占位文字：`输入命令或搜索...`
- 支持中英文模糊匹配
- 输入即时过滤下方的命令列表

### 3.2 默认命令列表

打开命令面板后默认显示的常用操作：

| 命令 | 作用 |
|------|------|
| **新建会话** | 添加一台新的 SSH 服务器配置 |
| **新建终端** | 在当前会话下新开一个 shell 标签 |
| **水平分割** | 当前终端上下分屏 |
| **垂直分割** | 当前终端左右分屏 |
| **重新连接当前会话** | SSH 断线后一键重连 |
| **删除文件列表** | 清理本地缓存（管理功能） |
| **切换主题** | 在深 / 浅主题之间切换 |
| **打开设置** | 进入全局设置面板 |
| **外观设置** | 调整字体、配色、UI 缩放等 |
| **管理会话卡位** | 调整左侧会话列表的布局（高亮选中项） |

### 3.3 使用技巧

- **键盘导航**：`↑` / `↓` 选择，`Enter` 执行，`Esc` 关闭
- **快速过滤**：输入「分割」即可看到所有分屏相关命令
- **支持自定义**：可在设置中绑定自己的快捷键到任意命令

## 四、SFTP 文件浏览器

![SFTP](screenshots/04-sftp.png)

SFTP 文件浏览器是 **图形化的远程文件管理器**，免除命令行下 `cd`/`ls`/`rm` 的繁琐。

### 4.1 顶部工具栏

从左到右依次为：

| 按钮 | 功能 |
|------|------|
| **标题** | `SFTP 文件浏览器` |
| **地址栏** | 当前远程路径（如 `/Users/ycs/`） |
| **定位** | 跳转到地址栏输入的路径 |
| **上传（↑）** | 选择本地文件 / 文件夹上传 |
| **下载（↓）** | 选中文件下载到本地 |
| **新建（+）** | 新建目录或文件 |
| **删除（垃圾桶）** | 删除选中项 |
| **刷新（循环箭头）** | 重新加载当前目录 |
| **关闭（×）** | 关闭 SFTP 浏览器 |

- 左侧绿色状态提示：`已连接` / `传输中`

### 4.2 主内容区（双栏布局）

#### 左侧：远程文件树

- 顶部：当前目录路径
- 下方：层级树形结构，文件夹图标 + 名称
- 可见的常见目录：`cargo` / `.cache` / `electron-gyp` / `.config` / `.local` / `.npm` / `.ssh` / `.vim` / `.vscode` 等
- 点击展开 / 折叠子目录
- 当前选中目录会同步到右侧文件列表

#### 右侧：远程文件列表

四列详情视图：

| 列 | 内容 |
|----|------|
| **名称** | 文件 / 文件夹名 + 图标（区分类型） |
| **大小** | 自动单位（B / KB / MB / GB） |
| **权限** | Unix 权限位（如 `rwxr-xr-x`） |
| **修改时间** | `YYYY-MM-DD HH:MM` |

- 可见示例：`.asana` / `.cache` / `.cargo` / `.cheat` / `.config` / `.dotfiles` / `.gnupg` / `.npm` / `.ssh` / `.vim`
- 单击文件名选中，双击进入目录或下载文件

### 4.3 底部状态栏

- 当前目录总容量：如 `1.17 GB, 284 个项目`
- 选中项计数：如 `0 个项目`

### 4.4 高级用法

- **拖拽上传**：从 Windows 资源管理器拖文件到 SFTP 窗口即可上传
- **右键菜单**：右键单击文件 / 文件夹提供更多操作（重命名、复制路径、改权限等）
- **传输队列**：上传 / 下载时底部状态栏的「传输队列」可展开查看实时进度

## 五、命令片段管理

![命令片段](screenshots/05-snippets.png)

命令片段管理面板让你**把常用命令保存成可复用的片段库**，按分类组织，一键插入终端。

### 5.1 整体结构

- **标题栏**：`命令片段管理` + 关闭按钮
- **搜索栏**：占位文字 `搜索命令、标签...`，可按标题、命令正文、标签全文检索
- **新建按钮**：右上角蓝色 `+ 新建`，创建新片段

### 5.2 左侧分类栏

按业务场景分组的标签：

| 分类 | 数量 | 说明 |
|------|------|------|
| **全部** | 默认 | 显示所有片段 |
| **运维** | 4 | 日常运维常用命令 |
| **安装** | 4 | 软件安装 / 服务部署 |
| **其他** | 3 | 杂项 |
| **网站** | 0 | Web 相关（暂无） |

> 分类可在设置中自定义新增、重命名、删除。

### 5.3 右侧命令列表

每条片段包含：**标题**、**分类标签**、**描述**、**命令正文**。示例：

| 标题 | 分类 | 描述 | 命令 |
|------|------|------|------|
| `docker ps` | 运维 | 查看运行中的容器 | `docker ps` |
| `重启服务` | 安装 | 重启 nginx 服务 | `sudo systemctl restart nginx` |
| `服务状态` | 其他 | 查看 nginx 状态 | `systemctl status nginx` |
| `实时日志` | 运维 | 查看 app-1 容器的实时日志 | `docker logs -f --since "1h" app` |
| `display` | 其他 | 显示当前目录 | `ls -la` |
| `noBack` | 其他 | 禁止回退 | `set -o nounset` |

### 5.4 操作流程

1. **新建片段**：点击 `+ 新建` → 填写标题、分类、描述、命令正文 → 保存
2. **使用片段**：
   - 在底部状态栏快捷栏（首页底部）直接点击片段标题 → 命令插入到当前终端光标位置
   - 或在片段管理面板中点击片段 → 选择「发送到当前终端」
3. **编辑 / 删除**：在片段管理面板中右键片段 → 编辑 / 删除
4. **搜索**：搜索框输入关键词，按标题 / 命令正文 / 标签过滤

### 5.5 实用场景

- 把团队的部署脚本、排障命令固化下来，新人入职直接用
- 把复杂的 `docker` / `kubectl` / `systemctl` 长命令保存为片段，避免每次手敲出错
- 不同分类对应不同项目 / 环境（如 `生产` / `测试` / `开发`）

## 六、模块协作：典型工作流

TermX 的真正价值在于**多模块协作**，下面是几个典型工作流。

### 工作流 A：服务器初次接入 + 资源评估

1. 左侧「+ 新建会话」→ 填写主机 / 端口 / 凭据 → 连接
2. 右侧监控面板自动加载：查看 CPU / 内存 / 磁盘基线
3. 中间终端跑 `htop` / `free -h` / `df -h` 复核
4. 命令面板（`Ctrl+P`）→ 「垂直分割」→ 上：监控 tail 日志；下：执行部署命令

### 工作流 B：紧急排障

1. 命令片段管理 → 选中「实时日志」片段 → 一键发送到终端
2. 看到错误后，SFTP 浏览器定位到出错的配置文件 → 下载到本地
3. 本地修改 → 拖回 SFTP 上传 → 终端执行 `systemctl restart xxx`
4. 监控面板观察 CPU / 内存曲线是否恢复

### 工作流 C：批量部署多服务器

1. 左侧边栏新建多台服务器会话
2. 每台连接后，命令片段中的「安装」分类命令一键执行
3. 多窗格模式下，左窗跑生产、右窗跑测试，对比输出

## 七、界面设计原则

- **一屏化**：核心信息（终端 + 监控 + 文件）一屏可见，避免频繁切换
- **键盘优先**：所有操作可通过命令面板（`Ctrl+P`）或快捷键触达
- **深色友好**：默认深色主题，长时间运维不刺眼
- **中文优先**：所有界面元素、提示、文档均为中文，符合国内运维习惯
- **状态可视化**：CPU / 内存用颜色区分正常 / 警告 / 危险，一眼看出问题
